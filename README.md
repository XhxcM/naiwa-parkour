# 奶蛙跑酷

在目录中运行 `node serve.js`，然后打开 http://localhost:4173 。电脑和手机位于同一局域网时，手机使用电脑的局域网 IP 加端口 4173 访问。尚未部署公网地址。

也可直接打开 index.html（需要支持 WebGL 的现代浏览器）。所有游戏依赖都在本地。

- 手机：上滑跳跃、下滑翻滚、左右滑动换道。每次手势只执行一次。
- 电脑：左右方向键换道，上方向键或空格跳跃，下方向键或 S 翻滚。
- 开始菜单：左右箭头切换五套皮肤，点击“开始游戏”后奶蛙先转过身，再开始奔跑。电脑也可以用左右方向键选择皮肤、Enter 或空格开始。
- 空中可换道，跳跃时角色转身一圈；落地后才可再次跳跃。翻滚期间角色收拢身体向前滚动。
- 低栅栏只能跳过；矮通道栏可以跳过或翻滚；高通道栏只能翻滚；倒树必须换道。每排障碍至少保留一条通路。
- 右上角可暂停；暂停后可继续游戏或返回主界面，切出页面时自动暂停。

场景使用统一 Three.js 三维坐标、透视和光照。道路、草地、树、障碍一起随距离移动，物体接触地面并投下阴影。角色按 `design/reference-voxel-assets.png` 的黄色体素角色制作，场景加入了参考图中的栅栏、松树、阔叶树、灌木、草丛与石块。角色模型在待机、奔跑、跳跃和翻滚时始终使用固定缩放值。

五套皮肤为：奶蛙、圣诞奶蛙、睡衣奶蛙、宇航员奶蛙、探险家奶蛙。撞到障碍物后可选择重新开始或返回主界面。

`engine.js` 是玩法逻辑，`world.js` 是三维场景与角色，`game.js` 是输入和界面。`node engine.test.js` 验证核心规则。`browser.test.js` 使用 Playwright + Edge 验证桌面和移动端模拟操作。

美术方向使用参考资产图的明亮体素风格，与最初的写实插画参考有明确区别。

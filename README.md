# 林间疾跑

在目录中运行 `node serve.js`，然后打开 http://localhost:4173 。电脑和手机位于同一局域网时，手机使用电脑的局域网 IP 加端口 4173 访问。尚未部署公网地址。

也可直接打开 index.html（需要支持 WebGL 的现代浏览器）。所有游戏依赖都在本地。

- 手机：上滑跳跃，左右滑动换道。每次手势只执行一次。
- 电脑：左右方向键换道，上方向键或空格跳跃。
- 空中可换道，落地后才可再次跳跃。
- 倒木可以跳过，巨石必须换道。碰撞后可重新开始。
- 右上角可暂停，切出页面时自动暂停。

场景使用统一 Three.js 三维坐标、透视和光照。道路、草地、树、障碍一起随距离移动，物体接触地面并投下阴影。角色暂为临时模型，待收到用户图片后替换。

`engine.js` 是玩法逻辑，`world.js` 是三维场景与角色，`game.js` 是输入和界面。`node engine.test.js` 验证核心规则。`browser.test.js` 使用 Playwright + Edge 验证桌面和移动端模拟操作。
